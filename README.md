# rkeeper-xml

Скилл для LLM-агентов по XML-интерфейсу r_keeper 7: помогает составлять и разбирать запросы
`RK7Query` / `RK7CMD`, объясняет ошибки сервера и умеет проверить запрос на живом стенде.

Формат - открытый стандарт Agent Skills (папка с `SKILL.md`). Его подключают Claude Code,
claude.ai и другие агенты с поддержкой скиллов; любой другой модели можно отдать `SKILL.md` как
инструкцию вместе с папкой `references/`.

## Что внутри

- **Справочник по 118 командам** - дерево запроса и ответа из XSD, раздел "Практика" (что сервер
  делает иначе, чем написано в схеме) и примеры, проверенные на кассовом сервере r_keeper 7.26.
- **Протокол** - транспорт, конверт, статусы и тексты ошибок, ссылки на объекты (id/code/guid),
  единицы (количество в тысячных, деньги в копейках), блокировки, лицензии.
- **Сценарии** - заказ от создания до оплаты, возвраты, предоплата и банковский терминал,
  карты ПДС, доставка, стоп-лист, смены, опрос изменений.
- **Справочники** - какой справочник r_keeper стоит за каким элементом запроса.
- **`scripts/rk7.py`** - отправка запроса на стенд (Python 3.8+, без зависимостей).
- **`scripts/xsd_to_reference.py`** - генерация справочника из XSD.

Данных конкретного ресторана или стенда в скилле нет: адреса и пароли передаются только на время
сессии через переменные окружения.

## Установка

**Claude Code** - склонировать в каталог скиллов (для всех проектов):

```bash
git clone <url-репозитория> ~/.claude/skills/rkeeper-xml
```

На Windows это `%USERPROFILE%\.claude\skills\rkeeper-xml`. Для одного проекта - в
`.claude/skills/rkeeper-xml` внутри него. Обновление - `git pull`.

**claude.ai / Claude Desktop** - собрать архив и загрузить его в разделе Skills настроек:

```bash
git archive --format=zip --prefix=rkeeper-xml/ -o rkeeper-xml.zip HEAD
```

**Другие агенты с поддержкой Agent Skills** - положить папку в их каталог скиллов.

**Любая другая LLM** - дать содержимое `SKILL.md` как системную инструкцию и доступ к папке
(или загрузить `references/` как базу знаний). Без запуска скриптов теряется только проверка на стенде.

## XSD-схемы

Схемы принадлежат UCS и в репозиторий не входят - см. [`schemas/README.md`](schemas/README.md).
Скилл работает и без них; схемы нужны для перегенерации справочника под свою версию r_keeper.

## Проверка на стенде

```bash
export RK7_HOST=host:port RK7_USER=... RK7_PASSWORD=... RK7_INSECURE=1
python scripts/rk7.py --cmd GetSystemInfo --summary
python scripts/rk7.py query.xml --var orderGuid={...}
```

На Windows (PowerShell) - `$env:RK7_HOST = "host:port"` и т.д. `RK7_INSECURE=1` нужен для
самоподписанных сертификатов, которые обычно стоят на кассовых серверах. Подробности -
`python scripts/rk7.py --help`.

## Как пополнять

Самое ценное в скилле - наблюдения с реальных серверов: где сервер расходится со схемой, какие
настройки ресторана мешают команде, какие ошибки что означают.

1. Проверьте поведение на стенде (`scripts/rk7.py`).
2. Добавьте заметку или пример в `references/command_notes.json` - поля `notes`, `examples`
   (`title` + `xml`, конкретные id заменяйте плейсхолдерами `{{имя}}` из `references/protocol.md`)
   и `impact` (`read` / `write` / `danger`).
3. Перегенерируйте справочник: `python scripts/xsd_to_reference.py schemas .` (нужны XSD в `schemas/`).
4. Общие правила протокола - в `references/protocol.md`, многошаговые сценарии - в
   `references/workflows.md`.

Не коммитьте адреса стендов, логины, пароли и идентификаторы чужих ресторанов.

## Структура

```
SKILL.md                       инструкция для агента
references/protocol.md         протокол, ошибки, единицы, блокировки, плейсхолдеры
references/commands.md         индекс команд
references/commands/*.md       команды (генерируются)
references/command_notes.json  ручные заметки и примеры - источник для генератора
references/workflows.md        типовые сценарии
references/refnames.md         справочники r_keeper
scripts/rk7.py                 отправка запроса на стенд
scripts/xsd_to_reference.py    генерация справочника из XSD
schemas/                       сюда кладутся XSD (не в репозитории)
```
