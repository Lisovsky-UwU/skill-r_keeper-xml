# GetRefDataFiltered

xml-запрос GetRefDataLimited: Получить коллекцию

Схемы: `schemas/qryGetRefDataFiltered.xsd` (схемы ответа нет)
Влияние: только чтение

## Запрос

Обозначения: `!` обязательный атрибут, `?` необязательный элемент, `*` 0..n, `+` 1..n.

```
<RK7CMD>
  (одно из:)
    <Order>? [refItem]  - Фильтр по заказу
    <Station>? [refItem]  - Фильтр по станции
    <Waiter>? [refItem]  - Фильтр по работнику
    <Table>? [refItem]  - Фильтр по столу
    <OrderCategory>? [refItem]  - Фильтр по категории заказа
    <OrderType>? [refItem]  - Фильтр по типу заказа
  @CMD!: string = "GetRefDataFiltered"
  @RefName!: refName {114 значений, см. XSD}  - Название коллекции
  @RefItemIdent: integer  - Идентификатор элемента (если надо запросить один элемент), если задан, то атрибуты тэга RK7Reference не пишутся, маска (см. PropMask) задаётся для свойств элемента (а не коллекции!)
  @RefItemGUID: string  - Идентификатор элемента (если надо запросить один элемент), если задан, то атрибуты тэга RK7Reference не пишутся, маска (см. PropMask) задаётся для свойств элемента (а не коллекции!)
  @PropMask: string  - Маска свойств. Можно запросить ограниченный список свойств. * - все свойства, пусто - ничего. Для вложенных объектов необходимо указывать полный путь к свойству, либо использовать круглые скобки для общего префикса - свойства типа объект. Для перечисления свойств элементов коллекции нужно использов…
  @WithMacroProp: boolean (по умолчанию "0")  - Нужно ли добавлять генерируемые свойства
  @WithBlobsData: boolean (по умолчанию "0")  - Нужно ли добавлять BLOB поля
  @MacroPropTags: boolean (по умолчанию "0")  - если 1, то добавлять генерируемые свойства подтэгами PropXXX, где XXX общая часть имени подсвойства (до ^)
  @WithChildItems: boolean (по умолчанию "0")  - 0 - без дочерних элементов, 1 - только иерархия внутри справочника в разделе RIChildItems коллекции, 2 - дети в разделе items только из других справочников, 3 - и иерархия внутри справочника и дети из других справочников в разделе RIChildItems коллекции. Добавляется псевдосвойство RIChildItems, мож…
  @IgnoreEnums: boolean (по умолчанию "0")  - если 0 - перечисляемые типы как строки, 1 - перечисляемые типы и их множества как числа
  @IgnoreDefaults: boolean (по умолчанию "0")  - если 1 - не писать атрибуты, если значения свойств "по умолчанию"
  @DateTime: dateTime  - Фильтр по времени
```

## Пример: GetRefDataFiltered

```xml
<?xml version="1.0" encoding="utf-8"?>
<RK7Query>
  <RK7CMD CMD="GetRefDataFiltered" RefName="MENUITEMS" PropMask="items.(Ident,Code,Name)">
    <Station id="{{stationId}}"/>
    <Waiter id="{{waiterId}}"/>
  </RK7CMD>
</RK7Query>
```
