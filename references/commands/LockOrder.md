# LockOrder

[Касса, Кассовый сервер] Временная блокировка заказа

Схемы: `schemas/qryLockOrder.xsd`, `schemas/resLockOrder.xsd`
Влияние: изменяет данные

## Практика

- lockTime передавайте в формате дата-время от нулевой даты Delphi: 1899-12-30T00:02:00 = 2 минуты (проверено на 7.26.8). Формат чч:мм:сс из XSD (xs:time, например 00:01:00) сервер 7.26.8 принимает, но блокировку не ставит: Status="Ok", locked="0", и чужой lockguid тоже проходит (проверено).
- locked в ответе - заблокирован ли заказ после запроса. locked="0" при Status="Ok" значит, что блокировка не встала (чаще всего неверный формат lockTime).
- Пока блокировка действует, изменяющие запросы без того же lockguid получают отказ; SaveOrder с тем же lockguid проходит (проверено).
- Досрочно снять свою блокировку: LockOrder с тем же lockguid и lockTime="1899-12-30T00:00:00" - ответ locked="0", после этого заказ свободен (проверено).
- lockguid - произвольный GUID, придуманный клиентом.
- Без Station/Employee блокировка ставится от имени кассового сервера: в тексте 2219 будет "станция Кассовый сервер, оператор Кассовый сервер". Заказ, открытый на кассе, дает 2219 с именем станции и работника кассы, а locked="1".
- Изменяющий запрос без того же lockguid получает "Не получается заблокировать. Заказ заблокирован другим ключом блокировки" (RK7ErrorN 2219).
- CloseVisit не проходит, пока заказ визита заблокирован, даже удаленный (RK7ErrorN 2129) - дождитесь окончания lockTime.

## Запрос

Обозначения: `!` обязательный атрибут, `?` необязательный элемент, `*` 0..n, `+` 1..n.

```
<RK7CMD>
  <Order> [orderElement]  - Заказ
  <Station>? [refItem]  - Станция, от имени которой блокируется заказ
  <Employee>? [refItem]  - Работник, блокирующий заказ
  @CMD: string = "LockOrder"
  @lockTime: time  - Время, на которое нужно заблокировать заказ
  @lockguid: normalizedString  - Токен блокировки (идентификатор сессии блокировки). Если указан, то с заказом может работать только тот, кто использует такой же токен блокировки. С версии 7.6.4.005
```

## Ответ

Помимо общих атрибутов RK7QueryResult (см. protocol.md):

```
@locked!: boolean  - Флаг "Заказ заблокирован"
```

## Пример: LockOrder

```xml
<?xml version="1.0" encoding="utf-8"?>
<RK7Query>
  <RK7CMD CMD="LockOrder" lockTime="1899-12-30T00:01:00" lockguid="{{lockGuid}}">
    <Order guid="{{orderGuid}}"/>
    <Station id="{{stationId}}"/>
    <Employee id="{{waiterId}}"/>
  </RK7CMD>
</RK7Query>
```

## Пример: Досрочно снять свою блокировку

```xml
<?xml version="1.0" encoding="utf-8"?>
<RK7Query>
  <RK7CMD CMD="LockOrder" lockTime="1899-12-30T00:00:00" lockguid="{{lockGuid}}">
    <Order guid="{{orderGuid}}"/>
  </RK7CMD>
</RK7Query>
```
