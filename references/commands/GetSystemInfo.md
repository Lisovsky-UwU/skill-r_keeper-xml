# GetSystemInfo

[Кассовый сервер] Информация о сервере: версия, ресторан, дата смены

Схемы в наборе UCS нет - страница собрана из проверки на сервере.
Влияние: только чтение

## Практика

- Схемы в наборе UCS нет (есть только у GetSystemInfo2), но команда работает: версия сервера, ресторан, дата смены.

## Пример: GetSystemInfo

```xml
<?xml version="1.0" encoding="utf-8"?>
<RK7Query>
  <RK7CMD CMD="GetSystemInfo"/>
</RK7Query>
```
