# Изменения

## 0.4.2 - 2026-10-28

- LockOrder: удаленный заказ блокируется и "оживает" (пропадает deleted, finished становится 0), после
  чего SaveOrder пишет в него блюда; блокировка не меняет version заказа, изменения - увеличивают;
  короткий lockTime="T00:00:00" тоже снимает блокировку; несуществующий заказ - RK7ErrorN 2202.
- Сценарий "создать заказ и работать с ним под блокировкой" со сверкой version до и после LockOrder
  (LockOrder, workflows.md).
- Чужая блокировка - RK7ErrorN 2219 или 2110 (protocol.md). VoidOrder заблокированного заказа даже с
  тем же lockguid получает 2110; удаленный заказ по-прежнему отдает GetOrder (deleted, finished).
- CreateOrder: у нового пустого заказа version="0".
- Все проверено на сервере 7.26.8.

## 0.4.1 - 2026-10-08

- LockOrder: lockTime в формате чч:мм:сс из XSD сервер 7.26.8 принимает, но блокировку не ставит
  (Status="Ok", locked="0"). Рабочие форматы - T00:05:00 и 1899-12-30T00:05:00, примеры исправлены.
- LockOrder: досрочное снятие своей блокировки (lockTime="1899-12-30T00:00:00"), смысл locked в ответе,
  блокировка от имени кассового сервера без Station/Employee.

## 0.4.0 - 2026-10-04

- Схемы обновлены до актуального набора UCS. Новые команды CreaterkFriendsAnchor (лояльность
  r_k Friends) и VerifyAgeViaMax (проверка возраста через MAX); изменения в стоп-листе модификаторов
  (несколько за раз), SetDishRests (storeZeroQuantity), KDSSetDishData3 (StationName, kdsrate
  необязателен), ответах с составом заказа (KdsState, LoyaltyInfo). Проверено на сервере 7.26.8,
  кроме storeZeroQuantity и LoyaltyInfo - их не позволяет проверить конфигурация стенда.
- Команды, которые UCS убрала из набора: CheckLicense и ReloadWorkUdb сервер выполняет - их схемы
  сохранены в schemas/Hidden; ExchangePriority и OpenLowAlcKeg сервер не знает - удалены.
- Страницы для команд без XSD (GetSystemInfo, GetBatchOfGoodsList) - из проверки на сервере.
- Генератор удаляет страницы команд, схем которых больше нет; check.py ловит заметки под неверным
  именем команды и плейсхолдеры, не описанные в protocol.md.

## 0.3.0 - 2026-10-04

- XSD UCS для r_keeper 7.26 теперь в репозитории (`schemas/`, без изменений; права - у UCS, см. NOTICE).
- CI проверяет, что справочник совпадает с тем, что генератор собирает из схем и заметок.
- Генератор находит файл ответа без учета регистра имени (resFarCardsAnyInfoXml.xsd) - результат
  одинаковый на Windows и Linux.

## 0.2.0 - 2026-10-04

- Справочник пересобран на XSD UCS для r_keeper 7.26: 29 новых команд (CalcOrder4/5, IntentPayOrder,
  CorrectIntentReceipt, CancelSbpPay, CheckPassword, GetOrderMenuLimited, GetPrintedData, стоп-лист
  модификаторов, тарификация, маркировка, партии товаров, кеги и бутылки), 33 обновленные схемы.
  Новые команды проверены на сервере 7.26.8 (где позволяла конфигурация стенда).
- Из документации UCS: правила записи справочников через SetRefData и примеры.
- Протокол: Content-Type, кодировка (UTF-8, не windows-1251), команды без схем и схемы без команд,
  блокировка смены, ошибки в самих XSD.
- `rk7.py --crypt-password` - шифрование пароля для CheckPassword.
- Генератор переживает невалидные схемы UCS и всегда пишет LF.

## 0.1.0 - 2026-10-04

Первая версия.

- Справочник по 118 командам XML-интерфейса r_keeper 7, сгенерированный из XSD: деревья запроса и
  ответа, раздел "Практика", примеры, проверенные на кассовом сервере r_keeper 7.26.8.
- Протокол, типовые сценарии, связь элементов запроса со справочниками.
- `scripts/rk7.py` - отправка запроса на стенд, `scripts/xsd_to_reference.py` - генерация
  справочника, `scripts/check.py` - проверка целостности.
